# 奶龙 · 合成大奶龙

支持电脑与手机触控的网页合成小游戏。相同等级的奶龙碰撞后升级，九种角色按编号从小到大合成。

## 运行

下载仓库后，用浏览器打开 `dist/index.html` 即可游玩，无需编译或安装依赖。

也可以安装 Node.js 后，在项目目录执行：

```sh
node serve.cjs
```

然后打开终端显示的本地地址。修改 `dist` 中的文件并保存，刷新浏览器即可查看。

## 操作

- 电脑：移动鼠标瞄准，点击投放；也可用左右方向键和空格。
- 手机：在游戏区域左右拖动，松手投放。
- 按 P 或点击暂停按钮暂停；支持重新开始。

## 项目结构

```text
dist/
  index.html       游戏页面
  style.css        页面样式与手机适配
  game.js          投放、碰撞、合成与计分逻辑
  models/1–9.png   九个等级的透明角色素材
serve.cjs          本地预览服务器
```

当前版本包含较窄的合成区域、1–5 级加权随机投放和降低后的合成分数，成长图鉴与下一只预览区域已隐藏。

本项目为非官方同人小游戏。
